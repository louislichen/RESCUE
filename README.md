# RESCUE

Official implementation of RESCUE.

This publication branch contains the validated local span-repair prototype and
the R7/R8 selector tooling. The accompanying scope note documents the evidence
boundary: a small, single-model, single-dataset pilot with descriptive results
only. Strict actual-cost matching is `NOT_VERIFIED`; Teacher advantage is
`NOT_ESTABLISHED`; Teacher–Student divergence is not supported. Nothing in this
branch claims effectiveness, efficiency, speedup, causality, or generalization.

See [docs/RESCUE_PILOT_SCOPE.md](docs/RESCUE_PILOT_SCOPE.md) for provenance,
CPU-only checks, and claim-safe usage guidance.
