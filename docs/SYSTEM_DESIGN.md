# RESCUE 三模块执行系统

完整入口在 [rescue](../rescue/README.md)，用于取代逐实验脚本拼接的主执行路径。
旧实验、原型及冻结报告仍保留自己的历史含义。

## 一轮执行

1. Prefill/完整验证提供上一已完成 query 的 T/S 注意力。两个原生 KV 缓存维护同一
   已提交前缀，长度控制不能取得未来未验证 query 的 Target 真值。
2. 模块3先计算不依赖位置集合的注意力摘要；异步时与模块1选择 R 重叠。
3. 模块1发布 `ContextPacket`，携带请求、轮次、前缀和工作集版本。模块2立即准备
   工作 KV 与映射内容；模块3同时完成依赖 R 的特征、风险与成本评分。
4. 模块2保持当前 query 的逐层门控，先生成一个必需的草稿 token；在第二个 token
   开始前消费匹配的 `LengthPacket`。包迟到就等待；网络异常明确回退，不多生成尾部。
5. 按 k 完成草稿，Target 用完整原生 KV 验证。接受前缀和纠正/bonus 提交后，
   拒绝尾部从两模型有效缓存中回滚；只有非终止全接受轮需要补算 Student 最后输入。
   Draft逐步保留末层RoPE后Q，验证并裁剪后，只为下一轮计算选中Q的完整键注意力；
   终止轮不计算下一轮探针。若未来M3消费草稿内实时注意力，这一省略需重新评估。

这里将模块1、3放在同一轮规划，并行执行可独立的部分。原有读取误差等特征仍依赖R，
因此保留必要的因果依赖；没有把旧预测器改名为完全独立的长度模块。

## 缓存与内容所有权

| 状态 | 生命周期与写入规则 |
|---|---|
| Native Target KV | 请求级预分配；只追加真实模型状态，回滚有效长度；始终完整 |
| Native Draft KV | 请求级预分配；写入原生投影，内容注入不能覆盖它 |
| Working Draft KV | 默认跨层批量读取R，只追加当前轮新状态；轮结束停止读取。可选增量模式保留物理slot，重绑定前恢复旧注入V并更新改变的位置，新请求清空映射 |
| Mapper 内容 memo | 请求内按已提交绝对位置缓存投影、内容与静态门控仿射项；来源和原生状态冻结后可复用，新请求清空有效标记 |
| 当前 query gate | 每层每 query 重算；原地更新私有工作 V，不沿用上一 query 的最终 gate |
| 规划快照与消息 | 请求/轮次/前缀/工作集版本绑定；异步任务完成后才复用相应状态 |

门控仍是 V-only，层来源从已训练 mapper 配置加载。没有声称任意 K+V 注入、任意层数
映射或精确 token 语义纠错已验证。默认 token 覆盖选择与历史读取保持选择是两个算法。
可配置层/token预算以真正跳过对应计算；`injection_rule=joint`可复用模块1的联合注意力
排名，但不是复用其全部边际覆盖增益。它也没有改变门控训练时的Teacher注意力输入。

## 调度和分布边界

`auto`在本地单 GPU 采用串行控制，避免已观察到的线程/流争用；配置远程长度服务时
才默认异步。`serial`/`async`均可显式指定。是否覆盖新增延迟，以消息到达首token
截止点与整请求计时共同判断，不能只比较模块耗时之和。

TCP 长度通道已有真实实现，可运行在独立 CPU 进程或可达可信主机。Target/Draft模型
执行当前仍在同一设备；跨节点传输完整上下文/teacher V、异构设备推理、网络带宽
适配与多请求服务并未被这条长度 RPC 自动完成。需要模型分区时，可沿ContextPacket
接口增加内容提供器，不能为了等待长度而打包阻塞上下文。

## 性能验证口径

兼容模式保留旧选择、旧风险与成本，核对接受轨迹；融合后端单独报告数值变化。
覆盖/缓存刷新和新成本的完整配置作为系统整体测量，不把其速度变化全部归因于调度。
成本校准只读取训练文档，现有验证集复用应明确记录。Teacher AR保留为独立对照，
系统相对旧pipeline的加速与超过Teacher是不同结论。
