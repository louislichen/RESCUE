# VSCode 新会话启动提示

在 RESCUE 工作区打开新会话后，可直接发送：

```text
请接续 RESCUE 项目的论文撰写。
先读取 AGENTS.md 和 docs/PAPER_HANDOFF.md，再根据其中的索引核对相关实验报告。

沿用我们已经确定的三个模块：
1. 基于大小模型注意力和内容边际增量选择 token/chunk 位置；
2. 基于层间对应，通过 mapper 和动态门控进行选择性内容补充；
3. 根据注意力、覆盖及补充后的 student 状态决定草稿长度。

论文围绕“关注哪里、补什么/补多少、指导能维持多久”展开。
请区分用户希望提出的架构、当前实际实现、已有证据和待验证假设；
特别不要将旧的读取保持实验，写成新的信息增量覆盖算法已经有效。

先给出论文核心问题、研究假设、贡献候选和章节提纲，再按我的要求逐节写作。
未完成的结果标为待验证，不编造数值、参考文献或有效性结论。
当前先做论文写作，不自动启动新实验。
```

在本地拉取仓库后，从本地 RESCUE 根目录打开 VSCode 工作区即可使用以上提示。
交接资料与结果报告均使用仓库内相对路径，无需复现服务器的目录或 GPU 环境。

如果新会话没有自动读取项目入口，可以先发送：

```text
请读取当前 RESCUE 工作区中的 docs/PAPER_HANDOFF.md，接续这里记录的论文架构与研究上下文。
```
