# 第二阶段结论：2026-10-14

E1—E9 实验组已完成，并补做并集来源消融、数据重建和数值复核。完整协议、逐方法表格、置信区间与复现命令见 [report.md](report.md)，实现见 [README](../README.md)。

本轮为 Qwen2-7B-Instruct → Qwen2-1.5B-Instruct / H100 / 原生 student KV：24 个训练样本、12 个验证样本、30 个测试样本。三个集合的文档标题互不重叠，并排除此前使用的文档。预算 256/512，最多生成 32 token，draft k=4。原始 BF16 与 FP32 teacher 复核使用各自参考，结果分别解释。

## 主要发现

1. **注意力筛选有效，但 teacher 独有优势还没有证明。** 离线 256 预算下，teacher-token 相对近期/随机筛选的下一 token 命中率分别提高 11.94/11.39 个百分点，配对区间均大于零。相对 student-token 的差异没有稳定优势。它支持保留重要历史位置，不足以证明大小模型的性能差距主要由注意力造成。

2. **Token 粒度有一个局部正向信号，并集没有额外稳定收益。** FP32 teacher / BF16 student 的 512 预算下，teacher-chunk、teacher-token、并集的合计接受率为 59.62%、62.22%、62.78%，decode TPS 为 25.41、26.22、26.28。Token 相对 chunk 的吞吐比 1.0317，95% 区间 [1.0057, 1.0599]；并集相对 token 为 1.0022，[0.9888, 1.0182]。并集相对 token 的接受率增量 +0.55 个百分点，区间 [-0.69, 2.03]。256 预算没有对应的正向收益，不能宣称并集优于 SpecExtend。

3. **差异大小不能直接当成保留收益。** 全局差异排序没有稳定增益，点估计反而下降；保护 student 核心位置后缓和了下降，但仍未超过 teacher-token。移除 teacher/student 独占峰值并等预算补齐的消融，也没有稳定的并集来源贡献。

4. **层间对应可重复，但还不能据此保证有效干预。** 独立测试的远历史平均 JS：相似度配对 0.173，相对深度 0.208，随机配对 0.285；训练/测试最近配对一致率约 36.1%。对应层的弱注意力偏置降低 KL，却没有增加 top-1 命中率，随机层与位置打乱也能降低 KL。按层选位未带来稳定接受长度增益，实际检索开销使其慢于共用工作集。

5. **保留收益有可利用信号，但当前选择器没有学到。** 在相同候选池和八位置联合替换下，离线 oracle 的 KL 改善为 0.0235 [0.0056, 0.0451] / 0.0209 [0.0069, 0.0382]，两个预算都为正；本轮没有增加 oracle 的 top-1 命中率。选择器训练用了 2,304 个真实替换收益标签，验证 MSE 0.00739，劣于零预测的 0.00506，相关系数 -0.069。局部联合替换未获得稳定收益，全局选位显著退化。这里的 query 特征主要是第一层 token 嵌入，且单次替换标签依赖原工作集；不能由此否定更完整的条件收益选择器。

6. **当前实现没有达到最终加速目标。** FP32 复核中 teacher 单独生成 decode TPS 47.13、含 prefill 总 TPS 22.38；完整 student KV 的普通 SD 为 31.26 / 17.02。所有筛选变体均未超过 teacher 单独生成。512 预算的约 3% 信号只是相对本轮 teacher-chunk 对照，不能表述为端到端加速。

## 数值一致性与完成检查

- 真实模型关闭干预、全量 gather 与原生输出完全一致；FP32 小模型稀疏读取与密集屏蔽参考最大误差 2.38e-7。预算、生成后缀、缓存回滚检查通过；数据重建的三个文件哈希完全相同。
- 原始 BF16 780 次 SD 中有 104 次未匹配逐 token teacher 参考；完整上下文对照的 4 个分歧文档，在同一 canonical KV 前缀下复现了单 query / 批量 query 的 argmax 分歧。固定形状改变未来 token 时，当前输出差为零，支持数值路径而非因果泄漏的解释。
- 独立 FP32 teacher 复核的 **420/420 次 SD** 输出与对应参考一致。它改变了 teacher 的数值目标，不等同于证明原 BF16 路线已经无损。
- 核心测试记录齐全：离线 4,060、原始运行 810（含 30 个 teacher 参考）、联合收益 600、并集消融 464、FP32 复核 450（含 30 个参考）。见 [completeness.json](completeness.json)。

## 下一步

优先研究**在当前 query 和工作集条件下预测增量收益，并进行小幅、可拒绝的门控补充**。特征需要加入深层 student 状态与候选内容信息，监督需要检查联合操作的实际输出损失，并继续用真实接受率验证。原生 KV 的保留收益与后续 teacher-V 注入收益要分别测量。

本轮为单模型对、单种子、30 个测试样本，区间未作多重比较校正。两模型均为 28 层，尚未验证不同层数、8K/32K、头级映射、非均匀层预算或 mapper。Teacher-chunk 是 Qwen2 线性 drafting 上的 SpecExtend 式选块对照，不是原版 Vicuna 树解码复现；eager 实现的速度也不能直接外推到 FlashAttention 或 RTX 4090 部署。
