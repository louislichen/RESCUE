# Q 可表达分数与正交残差补齐

目标是检验：小模型的 Q 在固定 K 时无法表达的 teacher 注意力分数差，能否由额外 token 分数偏置补上，以及这种补齐是否改善留出题目的推测解码接受率。

## 分解与补齐

对一个 query、一个小模型 attention head，设经过 RoPE 的可见 key 矩阵为 \(K\in\mathbb R^{N\times d}\)，当前分数为 \(s=Kq/\sqrt d\)，目标注意力为严格正的 \(p_T\)。本轮 \(d=128\)。softmax 不受整行常数影响，因此使用中心化矩阵 \(C=I-\mathbf1\mathbf1^\top/N\)：

\[
g=C(\log p_T-s),\qquad X=CK,
\]
\[
r_Q=X(X^\top X)^+X^\top g,\qquad r_\perp=g-r_Q.
\]

其中 \(r_Q\) 能由单个 query 的更新产生：\(\delta q=\sqrt d\,(X^\top X)^+X^\top g\)。\(r_\perp\) 与该分数空间正交，通过修改 Q 无法表达，可以直接作为 token 分数偏置加入。

\[
s'=s+\alpha r_Q+\beta r_\perp,\qquad p'=\operatorname{softmax}(s').
\]

当 \(\alpha=\beta=1\) 时，忽略有限精度误差，\(p'=p_T\)。当两者相等时，该方法等价于直接加入完整分数差；分解本身没有额外表达能力。只有不同强度的校准结果优于完整偏置对照，才支持分解有实际价值。

这里的 Q 可表达部分是**每个解码 query 的推理时分数投影**，不是新训练的共享 Q 权重。能够逐状态写出 \(\delta q\)，不保证存在同一个 \(\Delta W_Q\) 在所有隐藏状态上产生这些更新。

## 两类目标

1. **当前 teacher 完整注意力**：在校准集 teacher 固定续写前缀上，同时获取大小模型当前 query 的注意力；取对应 teacher 层的头平均，作为每个 student 头的完整 token 目标。用于诊断几何可达性，不用于接受率干预。生成位置检查 0、8、16、24、31，遇 EOS 停止。
2. **prompt teacher 文档条件分布**：每题只在 teacher prompt 的最后一个 query 获取一次注意力，取对应层的头平均，只使用文档 token 的条件分布。接受率实验全部使用这一可复用 prior；不获取生成时的 teacher 注意力。

第二类目标的原始分数差在文档位置为

\[
d_j=\log p_{T,\mathrm{doc}}(j)-\log\operatorname{softmax}(s_{\mathrm{doc}})_j,
\]

其他位置为零，再对整行中心化后分解。在完整强度 1 下，替换的是文档内部的条件注意力，保留原文档总质量以及非文档位置的概率；中间强度不保证文档总质量保持不变。单独加入投影或残差会影响非文档位置，两者全量相加时这些影响抵消。

文档区域沿用上一轮 token 坐标，排除首 token、问题和生成区。teacher prior 归一化前以 \(10^{-12}\) 作概率下界，几何诊断的完整目标也使用这一数值下界。大小模型头数差异通过对应层 teacher 头平均消除，没有学习头匹配。本轮两模型都是 28 层，未验证不同层数的映射。

## 实验与对照

- 复用原始划分：训练题 0–127；本轮只使用校准题 128–159 选择强度，测试题 200–249。没有新增训练数据或逐状态标签拟合。
- 测试题已用于项目此前的探索比较，这里的留出仅指本轮不使用它们拟合或选择强度，不是全新外部测试集。
- 复用上一轮固定 teacher 的测试续写文件 `out_fixed_teacher_audit/teacher_reference.jsonl`；draft k=4、最多生成 32 token，实际运行 student 草稿、KV 回滚、校正和全接受 bonus。全部路线以同一份 teacher token 为目标。
- 只干预最后四层，从 prompt 最后一个 query 开始；此前 prompt KV 来自原始小模型。生成区的 key 由实际干预后的前向重新计算，不使用冻结的生成区缓存。
- \(\alpha,\beta\in\{0,0.25,0.5,1\}\)，在 32 题校准集上按实际总量接受率选择；平局优先更少验证块，再优先较小的强度平方和。包括零干预。
- 分别选出只投影、只残差、完整直接偏置和分解组合。组合搜索包含零干预、单分量和等强度结果，必须据所选参数解释它最终实际做了什么。
- 加入已训练的 `q_native_attention` checkpoint，比较原生完整 Q 更新、Q 更新加正交残差、Q 更新加完整偏置。保留原 checkpoint，不重新训练或使用测试集选择参数。
- 打乱文档位置的 teacher prior 使用与真实 prior 相同的分解组合强度，不重新校准；每题同一置换用于全部四层。它检查 teacher 文档位置是否有额外价值。
- 95% 区间按题配对 bootstrap 2,000 次。接受率为所有题的总 accepted / 总 proposed；记录验证块数。

新的完整偏置使用未截断、依赖当前 student 分数的文档条件分布替换，与上一轮截断到 [-2,2] 的静态 log-prior 偏置是两个变体。

## 实现校验

`geometry.py` 使用实际 RoPE 后的 GQA key，按 KV 组计算中心化最小二乘投影。以 FP64 保存前缀 key 的和与 Gram 矩阵，每次 query 加入实际生成区 key 的统计量；全秩时使用 Cholesky，秩不足时使用特征值伪逆。避免每次 query 都对整个可见前缀作 SVD。

校验包括：零干预 logits 与原始模型完全一致；统计量投影与密集 SVD 比较；\(\delta q\) 对应分数与投影一致；投影加残差恢复目标概率；干预后的多步生成 key 与密集 SVD 比较；冻结 prompt 前缀 key 完全一致。正式评测还逐题核对 baseline 和原生 Q 的提议、接受、每个验证块及最终输出，要求与上一轮固定 teacher 复核完全一致。

FP64 概率闭合校验是数学实现检查。模型前向最终仍将分数转为 FP32、注意力转为 BF16；不能把约 \(10^{-16}\) 的校验误差当成 BF16 模型实际概率精度。

## 几何诊断结果

32 个校准题共检查 129 个生成状态、516 个层/query 组合，每个组合内平均 12 个 student head，再对组合取平均。

| 目标 | Q 可表达分数差能量比例 | 残差能量比例 | 原始注意力 KL | 只投影后的 KL | 全量补齐后的 KL |
| --- | ---: | ---: | ---: | ---: | ---: |
| 当前 teacher 完整注意力 | 78.39% | 21.61% | 1.3822 | 0.8514 | 约 0 |
| prompt teacher 文档条件分布 | 81.47% | 18.53% | 0.7839 | 1.1717 | 约 0 |

该比例衡量去掉常数后的 **log-score 差**，不是概率质量比例，也不是接受率。它允许每个 query 自由选择自己的更新，不是共享 Q 权重的能力上限或泛化保证。只投影使用欧氏分数距离的最小二乘，未最小化注意力 KL，因此第二类目标的 KL 反而增加。

全量补齐恢复概率的最大 FP64 误差为 \(6.66\times10^{-16}\)；残差相对正交误差最大为 \(2.21\times10^{-14}\)。复用前缀统计量与密集 SVD 投影的最大分数差为 \(7.46\times10^{-13}\)，连续 17 个干预 query 后为 \(1.19\times10^{-12}\)；冻结前缀 key 和零干预 logits 完全一致。

当前 teacher 文档条件分布相对于 prompt 静态 prior 的平均 KL 为 1.2758，包含首个状态和后续生成状态。生成过程中 teacher 关注位置会变化，静态 prior 的完整对齐不能替代对当前 teacher 注意力的对齐。

按生成位置看，首个状态几乎没有 prior 漂移；位置 8 的平均文档条件 KL 为 1.5223，位置 31 为 1.8633。晚期状态只包括尚未 EOS 的题目。各位置汇总保存在 `out_geometry32_test50/geometry_by_position.json`，可由 `geometry_rows.jsonl` 分组重算。

## 校准结果

共评估 23 组候选，全部只使用 32 个校准题：16 组普通模型的二维强度组合、4 组已训练 Q 的残差强度和 3 组已训练 Q 的非零完整偏置。

| 路线 | 所选 \(\alpha\) | 所选 \(\beta\) | 校准接受率 | 校准验证块数 |
| --- | ---: | ---: | ---: | ---: |
| baseline | 0 | 0 | 57.507% | 266 |
| 只加 Q 可表达部分 | 0.5 | 0 | 58.103% | 262 |
| 只加正交残差 | 0 | 0 | 57.507% | 266 |
| 完整直接偏置 | 0.25 | 0.25 | 57.776% | 265 |
| 分解组合 | 0.5 | 0 | 58.103% | 262 |
| 已训练原生 Q | 0 | 0 | 59.577% | 267 |
| 已训练 Q + 正交残差 | 0 | 0 | 59.577% | 267 |
| 已训练 Q + 完整偏置 | 1 | 1 | 60.569% | 262 |

分解组合最终退化为只投影；两条单独补残差的路线都选择了零干预。因此它们的所选模型测试结果相同，不能把重复结果解释为独立证据。普通模型直接施加完整补齐（\(\alpha=\beta=1\)）在校准集为 56.112%，低于 57.507% 的 baseline；逐状态对齐到静态注意力目标不自动提高接受率。

## 50 题固定 teacher 测试

| 方法 | 接受 / 提议 token | 接受率 | 相对 baseline，百分点 | 95% 配对区间，百分点 | 验证块数 |
| --- | ---: | ---: | ---: | ---: | ---: |
| baseline | 931 / 1489 | 62.525% | — | — | 390 |
| Q 可表达分数投影，\(\alpha=0.5\) | 922 / 1522 | 60.578% | -1.947 | [-3.239, -0.661] | 396 |
| 只加残差，选中 \(\beta=0\) | 931 / 1489 | 62.525% | 0 | [0, 0] | 390 |
| 完整直接偏置，强度 0.25 | 931 / 1484 | 62.736% | +0.211 | [-0.968, 1.413] | 389 |
| 分解组合，选中只投影 | 922 / 1522 | 60.578% | -1.947 | [-3.239, -0.661] | 396 |
| 已训练原生 Q | 936 / 1470 | 63.673% | +1.148 | [-0.603, 3.029] | 393 |
| 已训练 Q + 残差，选中 \(\beta=0\) | 936 / 1470 | 63.673% | +1.148 | [-0.603, 3.029] | 393 |
| 已训练 Q + 完整偏置，强度 1 | 928 / 1500 | 61.867% | -0.659 | [-3.195, 1.953] | 397 |
| 打乱 prior 的所选分解方案 | 922 / 1516 | 60.818% | -1.707 | [-2.955, -0.473] | 396 |

所选分解方案相对直接偏置下降 2.158 个百分点，区间 [-3.907, -0.446]；相对打乱 prior 下降 0.240 个百分点，区间 [-1.189, 0.619]，没有观察到正确文档位置的额外收益。已训练 Q 加完整偏置相对单独 Q 下降 1.807 个百分点，区间 [-3.595, -0.020]，验证块数 393 → 397。

所有九条路线的 50 题最终输出均与同一份冻结 teacher 续写完全一致。baseline 和单独原生 Q 的每题提议数、接受数、全部块及输出，与上一轮固定目标复核逐项一致。没有按预测稳定性或实验结果剔除题目。

**结论：数学上能够补齐分布，当前静态 teacher 文档 prior 下的残差补齐没有带来稳定接受率收益。** 两条单独残差路线在校准集就选中了零干预；分解组合未选择补齐且在测试上降低接受率；已训练 Q 加完整偏置也劣于单独 Q。较弱的完整偏置仅有 +0.211 个百分点，区间包含零。不能据此否定动态 teacher 注意力或经过训练的 token 门控残差方法，也不能把几何可达性当成共享参数的泛化或加速保证。

本轮没有新增共享参数训练，也没有直接解冻原始 `q_proj.weight`；原生 Q 对照复用上一轮完整矩阵增量合并的 checkpoint。当前 teacher 动态注意力仅用于诊断，接受率实验仍使用 prompt 一次获取的 prior。后续更有价值的方向是解决 prior 随生成失配，并按 teacher 下一 token 的输出目标训练 query 条件残差；这些训练尚未开展。
