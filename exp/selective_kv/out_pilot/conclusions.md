# 选择性 V 内容注入：首轮结论

首轮 mapper 训练、独立测试和内容来源补充诊断全部完成。详细表格与配对区间见
[主报告](report.md)，冻结内容来源对照见[补充报告](source_controls_report.md)，
实现、结构、训练目标与复现见[README](../README.md)。

## 做了什么

Qwen2-7B → Qwen2-1.5B，H100，FP32 teacher / BF16 student，冻结两模型。
沿用上一阶段的 24 训练文档与 12 验证文档，另外采集 30 个未看过且标题互斥的测试文档。
输入 600–2048 token；历史读取预算 512，其中 128 个高 teacher 注意力远历史位置
允许内容校正。只在 student 最后四层注入 V；原生 K 与 Q/K 投影权重保持不变。
Teacher V 来源层是原训练集注意力配对确定的第 25、27、27、28 层。

每层 mapper 为 LN(512) → Linear(64) → SiLU → Linear(256)，映射全体 GQA
value-head 展平表示。输出按照原生 V 的 RMS 定标，经有界残差校正写入工作读取，
不覆盖 backing cache。可学习门控读取当前 student 深层 query、原生 V、teacher 内容
latent、位置及注意力特征，为每个 token/层决定连续注入强度。

比较原生完整 KV、相同 teacher-token 筛选不注入、重构损失 mapper、输出性能损失
固定强度 mapper、输出性能损失选择性 mapper，以及恒定门控、打乱内容对照。
性能目标是 KL(p_teacher || q_student) + 0.25 × teacher-argmax CE，加 0.01
有界残差惩罚；这不是直接对离散 greedy 接受率求导。所有 teacher 内容和 prior 都
来自已完成前缀，prior 使用上一完成 query；不逐草稿 token 重跑 teacher。

## 已得到的信号

- 相同筛选不注入的实际接受率为 **63.51%**；重构 mapper 强制非零诊断为 **63.29%**；
  性能固定强度为 **64.82%**；性能选择性门控为 **65.26%**。
- 性能固定/选择性方案相对相同筛选基线分别增加 **1.32 / 1.75 个百分点**，
  文档配对 bootstrap 95% 区间为 **[+0.20,+2.90] / [+0.53,+3.52]**。
  两者输出 KL 分别降低 0.0573 / 0.0461，区间均小于零。
- 选择性门控平均接受长度从 **2.457 → 2.495**，增量区间 **[+0.0087,+0.0869]**。
  离线下一 token 一致率 68.33% → 70.83%，增量区间包含零，不宣称一致率已稳定提升。
- 重构策略在允许零注入的验证选择中被拒绝；性能固定强度与性能门控都被保留。
  重构训练的最好输出验证点为 epoch 2，性能两种方案均为 epoch 8。

这支持在固定筛选基线下继续研究**输出性能监督的 V 校正**；不能把它等同于
任意 KV 注入有效，也不能和之前不同测试集的注意力偏置直接作因果优劣比较。

## 仍未达到预期的部分

- **选择性的独立收益未证明。** 门控比独立训练的固定强度 mapper 多 0.44 个百分点，
  比同一 mapper 的验证均值恒定门控多 0.61；两个区间下界都为零。
- **精确 token 内容对应未证明。** 打乱映射内容接受率 65.39%；冻结补充诊断中，对齐
  teacher V 是 65.26%，各层均值 teacher V 是 65.44%，没有稳定差异。
  现有 mapper 可能利用文档整体内容或输出校正方向，尚不能称为精准填补 token 缺失细节。
- **内容依赖有信号，但归因仍有限。** 将 mapper 和 gate 的 teacher V 输入全部清零后，
  接受率 64.35%；对齐相对零内容增量 +0.91 个百分点，区间 [+0.16,+2.00]，
  输出 KL 也显著更低。零输入属于训练分布之外的消融，不等同于公平训练的 native-only
  adapter 对照；不能据此证明新增 teacher 语义信息必不可少。
- **尚未稳定超过完整小模型 KV。** 完整原生 KV 接受率 64.35%；门控多 0.91 个百分点，
  区间 [-1.53,+3.25]。本轮最明确的收益是相对筛选后的原生 KV。
- **没有加速。** 筛选基线/门控的 decode TPS 为 29.74/27.20，门控比值 0.9147，
  区间 [0.9059,0.9282]；包含 prefill 总 TPS 为 16.35/15.57。
  完整原生 SD decode TPS 36.12，teacher 单独生成 46.86；mapper/门控开销未被接受收益抵消。

## 核验与范围

主实验 826 离线记录、240 运行记录（含 30 个 teacher 参考）；补充 354 离线记录、
90 个运行记录。**300/300 次 SD** 与独立 FP32 teacher 参考输出一致，补充对齐路线
的 accepted/proposed/block 计数和输出与主实验完全复现。零门控与原生筛选输出完全一致，
工作读取未修改 backing K/V，注入位置不包含 sink/recent，门控有限差分检查通过，
student 训练中没有权重梯度。训练/验证/测试使用 89/45/118 个 teacher-forced query 状态。

补充来源对照是在检查主实验打乱内容结果后提出的冻结探索诊断，没有再调权重或强度，
应与主实验预设对照区分。源文件初始执行哈希见 protocol.json，补充执行哈希见
source_controls_protocol.json；后续唯一计算功能扩展是新增 mean/zero 来源分支，
并修正 CLI 模块同名导入，未改训练目标或已选权重。

本轮 V-only、四个后层、rank=64、单种子、单模型对、约 2K 输入；尚未测试 K+V、
8K/32K、其它层段、多种子或重新训练的无 teacher-V 基线。完整 backing cache
与 student prefill 保留。Eager 时序不能直接作为优化后 SpecExtend 的性能结论。
