# 第二部分：注意力筛选与焦点诊断实验清单

记录日期：2026-10-14。

状态：本轮 E1—E9 实验组已完成（2026-10-14），另做并集来源消融和数值复核。实现与原始结果位于 [`../../attention_selection/`](../../attention_selection/README.md)；主要发现见[结论](../../attention_selection/out_stage2/conclusions.md)，完整协议与表格见[报告](../../attention_selection/out_stage2/report.md)。

实际执行范围：Qwen2-7B → Qwen2-1.5B、H100，24/12/30 个训练/验证/测试样本，256/512 两档预算。使用原生 student KV；两模型均为 28 层、头数不同。本轮 teacher-chunk 为 SpecExtend 式选块对照，不是原版 Vicuna 树解码复现；头级映射、非均匀层预算和 mapper 留待后续。

## 本阶段实验总览

| 顺序 | 实验 | 需要验证的问题 | 主要对照 |
|---|---|---|---|
| 首轮 | E1 筛选基线 | Teacher 选位是否改善 student 预测？ | 近期、随机、student、teacher 选块 |
| 首轮 | E2 筛选粒度 | Token 比 chunk 更精细是否带来收益？ | 同实际 token 预算的 teacher chunk/token |
| 首轮 | E3 峰值并集 | 大小模型关注位置是否互补？ | teacher-only、student-only、预算受控并集 |
| 首轮 | E7 差异筛选 | Teacher 关注而 student 关注不足的位置是否值得保留？ | 差异排序、差异加 student 核心保护、并集 |
| 首轮离线 | E4 层间对应 | 大小模型是否存在稳定的注意力功能对应？ | JS 热图、相对深度、相似度、随机配对 |
| 有对应信号后 | E5 权重干预 | 对应关系是否能指导有益的读取权重调整？ | 固定 KV，比较不同层配对、打乱位置和无干预 |
| 有对应信号后 | E8 按层选位 | 不同 student 层是否需要不同历史位置？ | 全层共用工作集、按深度选位、按对应关系选位 |
| 先诊断，再训练 | E9 收益选择器 | 能否预测保留位置的实际收益？ | 随机、attention Top-k、差异规则、离线 oracle、学习选择器 |
| 最后 | E6 实际收益 | 离线改善能否在可部署流程中提高速度？ | 真实接受轨迹、分阶段耗时、吞吐、输出一致性 |

首轮先使用一个模型对、一档缓存预算和约 20–30 个诊断文档。诊断与调参数据不进入最终测试；得到信号后再增加预算档位和全新测试文档。既有实验只作参考，本轮直接对照应匹配模型、数据、缓存预算和原生 KV 设置。

## 目标与边界

验证 teacher 注意力能否帮助 student 选择可读历史位置、调整读取权重，以及大小模型层间的注意力对应关系是否有实际预测价值。本阶段不引入 mapper 或 teacher V 注入，使用原生 student 历史 KV，避免把位置选择的作用与内容补充混在一起。

两类干预分别评测：

- 位置筛选：改变工作缓存中的位置集合，读取这些位置的原生 KV。
- 权重调整：固定工作缓存中的位置和原生 KV，只修改一个 student 层当前 query 的 attention 分数；后续层正常计算。

## E1：Teacher 筛选是否有效

在相同工作缓存 token 预算下比较近期选择、随机选择、student 注意力选择、teacher 注意力选择。初始比较统一使用 chunk 粒度，并统一最近位置的强制保留规则。

记录输出 KL、teacher 下一 token 命中率、实际 drafting 的平均接受长度和接受率。带证据位置标注的样本可额外记录证据覆盖和注意力质量，但不能只凭注意力差异断言它导致预测差距。

## E2：Token 筛选是否优于 Chunk 筛选

比较 teacher 注意力的 chunk 选择与 token 选择。匹配实际保留 token 数，使用相同 query、teacher 层/头聚合方法和近期保留规则。

检验更细粒度选择是否有额外预测收益，并记录 gather/缓存更新成本。不能用更多保留位置解释为粒度优势。

## E3：大小模型注意力峰值 Token 的并集

用户提出的待验证想法：同时保留 teacher 与 student 关注的峰值 token，检查是否优于 SpecExtend 仅由 teacher 引导的筛选。

设两者的候选集合为：

\[
P_T=\operatorname{Peak}(a_T),\qquad
P_S=\operatorname{Peak}(a_S),\qquad
U=P_T\cup P_S.
\]

动机假设：teacher 与 student 的关注位置可能互补；保留 student 自身依赖的位置，可能减少仅按 teacher 筛选时对 student 的干扰。这不是已得到的结论。

峰值定义待验证：第一版可以用 Top-k 高注意力位置，局部极大值作为后续候选定义。两种定义必须分别标注，不能混用。

主对照包括 teacher-only token、student-only token、并集 token，以及同预算原生 SpecExtend。teacher-only token 对照用于区分 token 粒度与并集规则的收益。

预算规则在验证集上固定：

- 所有路线使用相同总 token 预算 B 和强制近期位置集合；近期位置也计入 B。
- 并集去重后超出预算，按事先确定的模型配额或融合排名裁剪；不足预算时按同一补齐规则填满。记录实际保留数，避免重叠率导致预算不一致。
- 不裁剪的完整并集仅作为补充诊断，报告其实际缓存和耗时，不能据此声称优于同预算基线。
- teacher/student 配额与融合规则属于待选超参数，不通过测试集决定。

记录峰值重叠率、来源独占位置比例、teacher/student 独占位置的增量收益，以及接受长度和吞吐。

注意力必须对应可比较的历史、query 和位置。在线 student 注意力通常只覆盖当前工作缓存；对未观测位置不能直接赋零并解释为不重要。先用共同完整历史做离线诊断，后续部署实验仅使用实际可获取的注意力，计入额外采集成本。

## E4：大小模型层间对应是否稳定

对相同 query、共同位置上的注意力先做层内头平均，计算 student 层 × teacher 层的 JS 距离热图。分别检查近期与远历史，避免局部注意力共同占优造成虚假的对应。

在诊断/验证数据上比较相对深度配对、相似度配对和随机配对；在新文档上检查稳定性。层级存在信号后再细化到头级，不预设严格的一一对应。

## E5：对应关系能否指导有益的权重干预

固定工作缓存和原生历史 KV，单次只干预一个 student 层。比较无干预、相对深度配对、相似度配对、随机层配对和打乱 token 对应关系的 prior。

对因果可见位置，使用弱到强的 attention 分数偏置：

\[
s'_{h,i}=s^D_{h,i}+\lambda\big(\log a^T_i-\log a^D_{h,i}\big),
\qquad a'_h=\operatorname{softmax}(s'_h).
\]

保留 causal mask，对 log 概率作数值保护。先离线测下一 token 预测；有收益的配置再测实际 drafting。强度、配对和层选择只由验证集决定，同时报告同强度对照。

相似热图本身不证明注入兼容性。此处即便成功，也仅支持读取权重干预；teacher V 的映射兼容性需要在后续内容补充阶段另测。

## E6：收益能否在实际流程中保留

分别报告离线当前-query teacher 诊断和仅使用已完成验证阶段信号的实际路线。部署路线不获取未来 token，不忽略额外 teacher 前向或注意力采集成本。

测量选位、缓存更新、draft 和验证耗时，报告平均接受长度、接受率、decode 吞吐及包含 prefill 的总耗时。检查输出与一致数值路径的 teacher 参考是否一致。

## E7：注意力差异筛选与 Student 核心位置保护

基于并集讨论的候选扩展：筛选时区分 student 已依赖的位置与 teacher 关注、student 关注不足的位置。

先在共同历史、query 和位置上的可比注意力分布中计算启发式分数：

\[
d_i=a_T(i)\,[a_T(i)-a_S(i)]_+.
\]

比较 teacher-only token、student-only token、预算受控并集、差异排序、差异排序加 student 核心位置保护。保护 student 核心位置时，其配额与强制近期位置均计入总预算 B；和并集使用相同的配额调参范围。

差异只是候选信号，不是缺失信息或保留收益的标签。记录实际新增/移出位置、证据覆盖、预测损失和接受长度；区分核心保护的收益与差异排序的收益。

第一轮仅做离线完整历史对照。若 teacher 与 student 注意力来自不同 query、时间或可见范围，不能直接相减；在线可获取版本后续单独评测。

## E8：根据层间对应分别选择工作集

在 E4 得到稳定层间关系后，比较全层共用工作集、按相对深度的 teacher 来源选位、按注意力对应关系选位。允许 student 不同层使用不同的位置集合 R_l，并使用原生 K/V。

第一轮保持每个 student 层的 token 预算相同，只改变位置选择，避免与层级预算分配混淆。若随后研究不同层的预算分配，应匹配总实际 KV 字节预算，并报告各层预算和更新成本。

层配对只从诊断/验证数据确定，可使用多个 teacher 层的软权重。头级选择留作有层级收益后的扩展。缓存位置与 RoPE 语义需要正确维护，不能简单重编号历史 token。

## E9：预测 Token 保留收益的选择器

先用少量样本做移除/补回或等预算替换位置的反事实诊断，测量 teacher 输出对齐损失变化。检查真实收益是否能被 attention 大小、teacher/student 差异与当前 student query 状态预测。

在固定候选池、缓存预算和近期规则下，比较随机选择、teacher attention Top-k、差异规则、基于真实损失的离线 oracle 和学习选择器。位置收益依赖当前工作集，需额外检查选择多个位置后的实际联合收益，不把单位置收益简单相加当成保证。

Oracle 是使用评测预测结果进行选位的理想化诊断，不能计入可部署性能，也不能当成严格的数学上界。诊断收益可作训练集上的回归或排序标签；部署选择器只能使用当时可获得的特征，不使用真实下一 token、未来 teacher 状态或事后损失。

若 oracle 相对规则没有收益，或收益无法在留出文档预测，应先定位候选池与标签的问题，暂缓扩大选择器训练。本实验学习的是原生 KV 的保留收益，teacher V 注入收益在后续阶段另测。

## 共同协议与顺序

- 冻结大小模型权重；筛选实验保持原生 student KV，权重干预实验从相同原生缓存开始。
- 按文档分开训练/诊断、验证和全新测试；调参只用验证集，区间按文档配对计算。
- 筛选路线匹配实际缓存 token 预算和近期保留规则；不同上下文可见范围的注意力不能不经处理直接比较。
- 多个 teacher 层、头和注意力采集成本需要记录；不要预先把更复杂的策略视为更好的策略。
- 优先做 E1—E3、E7 的筛选比较，并行开展 E4 离线热图；关系稳定后做 E5、E8；E9 先做收益诊断再训练选择器；最后做 E6 的实际收益检查。

后续 mapper 和选择性内容补充实验另行设计，不属于第二部分的完成标准。
